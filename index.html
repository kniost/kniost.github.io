「动物森友会圈圈」版本更新说明

发表于 2026-08-11 分类于 动物森友会
本文字数： 9.2k 阅读时长 ≈ 8 分钟

动物森友会圈圈（以下简称动森圈圈）是集攻略，新闻，交友和绘图于一身的小程序！

更新日志

3.1.4

2026年8月11日

主要更新：

  1. 「我的设计」照片转像素画整体重做：新增「照片优化」预处理（默认开启），自动降噪并恢复细节对比度和饱和度，真实照片转出来的杂色明显减少、色盘更干净；另有轻量的「照片快速」档
  2. 新增「抖动」选项：用相邻两色交错模拟过渡色，人像肤色、天空渐变的层次更细腻（默认关闭，可在导入界面开启）
  3. 原「高 / 中 / 低平滑」模式全部保留；导入像素画截图请继续用「像素画」模式保持锐利
  4. 图片导入界面改版：每个设置项带名称标注（切分 / 预处理 / 抖动 / 取色算法），切分多图时预览会显示虚线分割参考线
  5. 绘制页改版：新增色盘快捷条，点一下直接换色、再点当前色进入取色器编辑；画笔 / 油漆桶切换为并排开关更直观；生成分享卡后新增「保存全部」按钮
  6. 设计切分为多格后新增编辑托盘：点缩略图即可切换当前正在编辑的格子，每格保留各自独立的调色板（与游戏内一致），随时可以合并生成或取消切分
  7. 新增「领取历史群积分」：小程序签到功能上线前的微信群积分，可以在「积分中心 → 领取历史群积分」申请迁回，管理员核对通过后到账

问题修复：

  1. 修复图鉴筛选栏切换分类时闪退的问题
  2. 修复从微信群消息卡片进入签到时，积分未计入所在群排行榜的问题
  3. 分享岛屿 / 大头菜岛屿改用固定分享图，避免 Dodo 密码被自动截图带进分享卡片（电脑端尤其明显）
  4. 修正「精美的画」「勇敢的雕像」的赝品鉴别说明
  5. 修复图鉴弹窗列表加载失败后一直为空、需要重进小程序才能恢复的问题
  6. 修复「量子化」取色算法在颜色较多时可能丢失大半色盘的问题
  7. 修复导入界面选项弹窗每次都从第一项开始、不定位到当前所选项的问题
  8. 修复「我的设计」署名偶尔仍显示旧岛名 / 旧玩家名的问题：现在每次进入绘制页都会重新读取护照信息并覆盖署名，读取失败时才保留原有署名

介绍

动物森友会圈圈（以下简称动森圈圈）是集攻略，新闻，动森串门，图鉴和绘图于一身的小程序！

想加入「动物森友会圈圈官方交流群」可以添加微信AC_circle，拉你进群~

已有功能介绍

※绘制我的设计

如果遇到问题，可以先尝试点击右上角，重新进入小程序。或者尝试将小程序删除后重新添加

在绘制我的设计中，你可以在白板上创作属于你自己的动森设计：

  • 白板创作，可以生成二维码，并使用Nintendo Switch Online的APP扫码直接传到游戏中
  • 可以扫描已有的二维码，获取别人的设计
  • 可以在别人的设计上直接进行修改
  • 可以使用图片直接生成图案，并支持切分
  • 支持油漆桶
  • 可以自由选择颜色，支持透明颜色

※制作动森护照

可以制作你的护照啦！精心制作，非常精美~

※大头菜市场 ※森友の邀请函

  1. 可以拍摄证明照片，支持自动排队，手动排队叫号，还能收到通知！

  2. 还能建立私有房间，只能房主分享，群内共享时不能转发

初心与历程

动森圈圈是在开始玩（肝）Switch的《集合啦！动物森友会》的时候，突然发现大家有很多不懂的东西，所以想做一个攻略形式的小程序，结果动森没肝肝了小程序……

前端不咋好，写canvas写多了感觉头都秃了。

当然攻略这一块也是之后要做的，想来贡献力量或者测试的可以加群共商大事！

美区账号申请指南

发表于 2020-03-30 分类于 动物森友会
本文字数： 1.1k 阅读时长 ≈ 1 分钟

无需信用卡注册苹果美区 Apple ID 帐号的指南

第一步 准备工作

1、一个没有注册过AppleID的邮箱，建议最好是如Gmail自己的邮箱

2、一个苹果手机，当然这个是必须的

3、需要科学上网，使用注册对应地区的节点，我们注册美区苹果账号使用美国节点

第二步 先到苹果网站注册账号

首选启用科学上网软件（手机电脑均可），选择美国节点，选择代理/全局模式，使目前网络使用了美国代理。

打开此网站创建您的AppleID： https://appleid.apple.com/account#!&page=create

可以是中文界面，但注意的是国家或地区，必须选择 【美国】

按要求填写完整，这步骤就不需要多讲，一步步填写，自己务必记住就行，找回密码或者解锁账号会用到这些问题答案。

然后会给你注册邮箱发一个6位数的验证码，输入后就完成了注册。若你是用来共享的账户，登陆后不推荐启用两部验证，这个共享的话会很麻烦，每次都需要进行登陆验证。

电脑端注册账号就结束，然后下面是使用手机登陆App Store。

第三步 苹果手机App Store登陆

手机必须是代理模式，节点选择美国。首先退出原来的账户，登陆新注册的账户。

会出现提示按提示选择Review，地区仍然是需选择美国United States，并操作同意下一步。

这个是关键的一步，下面会让你选择付款方式，若没有出现None，那么就你的手机网络不是美国IP，重新选择代理美国IP后，然后付款方式选择None。

对于Shadowrocket小火箭设置里面 【全局路由】 必须选择 【代理】；V2rayN软件的话代理选择全局模式。

填写美国人信息，这个建议谷歌搜索【美国个人信息生成】关键字获取。

需要注意的是，美区 App Store 中的应用是需要交税的，如果你希望以较低的价格购买一些付费 app，建议在地址处填入税率较低的州，比如 Oregon（俄勒冈州）、Alaska（阿拉斯加州）、Delaware（特拉华州）、Montana（蒙大拿州）、New Hampshire（新罕布什尔州）等。

填写后完成后，你的美区Apple ID账号就已注册完成了！

绘制我的设计说明

绘制我的设计与导入说明

本文主要分为两个部分，主要包括两个部分，可以点击直接跳转：

  • 小程序「动物森友会圈圈」中绘制我的设计功能
  • 生成的二维码如何导入《集合啦！动物森友会》

有小程序相关的问题可以在关于页回复哦~

在绘制我的设计中，你可以创作属于你自己的动森设计，并生成二维码，使用APP Nintendo Switch Online 的扫码直接传到游戏中。

绘制我的设计功能

主要功能如下图所示，其中绘制功能主要包括作画、图片切分与生成和扫码获取设计这三大功能，并对大量细节做了优化；生成功能包括信息修改和二维码生成，下面一一介绍。

作画

动森的画板为32*32大小。

绘画功能区介绍

绘画功能区如下图所示，按钮分别是：

  • 编辑作品名、作者名、岛名，如果出现空白则不能导入，可以再次扫码、修改、再次生成后再导入
  • 撤销和重做
  • 切换油漆桶和笔（油漆桶模式下只能单击）
  • 清除画板（同时也将重置调色板和生成的二维码）
  • 选择颜色，其中颜色是当前颜色

选择颜色

作画首先需要选择颜色，由于动森的数据设计问题，一幅图中只能最多存在15种颜色，我们把可以选择的15种颜色称为调色板，选择颜色时需要先选择调色板，并且在下方选择你需要的颜色，可供选择的颜色种类有160种。

还有一种是透明色，在调色板最后，该调色板不能更改

需要注意的是，调色板颜色发生变更时，图中所有使用该调色板的像素都将随之改变，作画时默认第一个颜色是背景颜色，可以通过修改第一个调色板的颜色来修改背景。

选择颜色后可任意作画，支持点和划两者方式进行绘制，既可以精细控制也可以大片涂抹。

图中蓝色区域为你的调色板颜色，绿色区域为你的可选颜色区域。

二维码与图片功能

从左至右依次是：扫码，生成二维码，图片选择

扫码获取设计

扫码获取设计指的是可以直接扫描他人分享的二维码并进行制作，可以支持从图片生成或者使用相机扫码。

生成二维码

生成二维码之前，可以点击信息按钮修改你的个人信息与作品信息，这个信息同样会带到游戏之中。

如果你选择的是图像切分模式，那么生成的二维码中标题将会带上编号，从左至右从上到下依次编号，方便在导入的时候确定位置。如果你没有选择切分，将直接生成一张二维码图像。

二维码图片放在下方的滑动栏中，可以单击进行预览，预览时可以点击保存到手机中。

如果没有清空画板或者退出的话，之前生成的二维码也都在下面的滑动栏中。

图片切分与生成

图片切分与生成是一个重要的功能，它能将图片转换为动森可用的格式，可以切分图片并且实时预览。

图片切分的选项有以下几点：

  • 图片切分：使用宽*高的形式表示，可以选择从1*1至7*7的49种比例切分图案
  • 透明界限：指的是如果使用带有透明度的图片，那么在多少透明度以下的会被忽略
  • 平滑度：指的是处理图片时所使用的平滑度，如果是卡通图片，使用像素化（原默认效果）可能效果更好
  • 颜色算法：目前分为量子化（中值滤波） RGB YUV 三种，可以自由选用查看哪个效果更好

需要注意的有以下几点：

  • 由于手机性能的限制，切分较多时生成多个二维码可能会导致设备发热，且等待时间较长。
  • 由于颜色种类的限制，建议使用颜色较少、对比强烈且无太多阴影的图片
  • 尽量使用原图，这样能更准确地提取颜色

二维码如何导入动森

在保存二维码之后，我们需要将所作的图片转移到动森之中，我们需要下面几样东西：

  • 一台非国行版的可以联网的Nintendo Switch，并安装了任意区域的数字版或实体版的《集合吧！动物森友会》，并更新到1.1版本以上
  • 一个购买了Nintendo Switch Online会员的账号
  • 一台手机，并已登录Nintendo Switch APP 如何下载登陆APP
  • 另一台可以显示二维码的设备（如电脑、别人的手机等）

Switch的设置

首先在游戏主界面，不要进入游戏。按➖号，点狸端机入口设置，对话后将联网进行同步，同步完成后即可，之后不需要再进行这个步骤。

如果联网有问题或者网速不够好，可以选择使用路由器端或者电脑端的网易UU之类的加速器针对Switch的网络进行加速。

导入步骤

  1. 点击手机APPNintendo Switch Online中的动物森友会（或Animal Crossing）即可登入狸端机入口站，在我的设计中点击读取新的QR Code，然后扫描二维码（在另一台设备上显示）
  2. 扫描后，你需要到Switch动物森友会游戏中的「我的设计」中，按下➕键下载
  3. 由于二维码的方式是3DS时代的操作，所以在《集合啦！动物森友会》中不能修改

需要注意的是，下载的时候只能有一张，所以有多个图片的时候，需要一张一张扫描和下载
